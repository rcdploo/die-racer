# DIE-RACER ARENA — Deployment Guide

## File Structure
```
die-racer/
├── app.py            # Flask + SocketIO server (the web wrapper)
├── main.py           # Your game (unchanged logic, env var + https fixes)
├── requirements.txt  # Python dependencies
├── render.yaml       # Render.com deploy config
├── templates/
│   └── index.html    # Browser terminal UI
└── stats.json        # Seed file — upload this too
```

---

## Step 1: Push to GitHub

If your project isn't already in a GitHub repo:
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/die-racer.git
git push -u origin main
```

## Step 2: Deploy on Render

1. Go to https://render.com and sign up / log in
2. Click **New → Web Service**
3. Connect your GitHub account and select your `die-racer` repo
4. Render will detect `render.yaml` automatically — click **Apply**
5. In the Environment section, find `WORDNIK_API_KEY` and enter your key:
   `iodw5ezxg3dgfuuh33p4idggzs8fjwnkgwwpgrh54vzym3wh0`
6. Click **Deploy**

Your game will be live at a URL like: `https://die-racer-arena.onrender.com`

> **Note:** The free tier spins down after 15 minutes of inactivity.
> The first visitor after a spin-down will wait ~30 seconds for it to wake up.
> Upgrade to the $7/month "Starter" tier if you want it always-on.

## Step 3: Seed the stats file

After your first deploy, upload your existing `stats.json` to the persistent disk:
1. In the Render dashboard, go to your service → **Shell**
2. Run: `cp /opt/render/project/src/stats.json /data/stats.json`

Or just let it start fresh — the app will create a blank one automatically.

---

## Step 4: Embed in Squarespace

1. In Squarespace, go to the page where you want the game
2. Add a **Code Block** (under Embed or Code in the block menu)
3. Paste this, replacing the URL with your Render URL:

```html
<iframe
  src="https://die-racer-arena.onrender.com"
  width="100%"
  height="620"
  style="border: none; border-radius: 8px;"
  allow="autoplay"
></iframe>
```

4. Adjust `height` to taste — 620px fits the terminal comfortably.

## Environment Variables Reference

| Variable | Description |
|---|---|
| `WORDNIK_API_KEY` | Your Wordnik API key (set manually in Render dashboard) |
| `SECRET_KEY` | Flask session secret (auto-generated by Render) |
| `STATS_PATH` | Path to stats.json (defaults to `/data/stats.json` on Render) |
